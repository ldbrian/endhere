## MVP：Book Voice 第一支（纯情绪）

**只做一件事**：翻开书、落在末尾空白页时，按一个概率，用一句书自己的纯情绪替换掉那天的 Window prompt。验证「书会主动活着」是否成立，并测出稀有度。

---

### 新建文件 `app/v2/_core/bookVoice.ts`

镜像 `personas.ts` 的简洁结构（不学 windows.ts 的扁平数组）：

```ts
export type BookVoiceId = string;            // 句子的稳定标识，用于埋点
export type BookVoice = { id: BookVoiceId; text: string };

export const BOOK_VOICES: BookVoice[] = [
  { id: 'glad_to_see_you', text: '今天，又见到你了。' },
  { id: 'nothing_to_write', text: '今天什么都不用写。\n翻开看看，也很好。' },
  { id: 'curious', text: '我有一点点好奇。\n这一页会写下什么。' },
  { id: 'waiting', text: '我一直在这里。\n不急。' },
  { id: 'remember', text: '有些页，我一直记得。' },
  { id: 'quiet_today', text: '今天没什么想说的。\n只是想待一会儿。' },
  { id: 'wonder_unwritten', text: '我不知道为什么，\n总觉得还有一页，\n你一直没有翻开。' },
  { id: 'uncertain', text: '我说不清。\n但今天，我想认识你多一点。' },
];

const BOOK_VOICE_RATE = 0.15;   // 15% 概率走 Book Voice（常量，可调）

// 决定本页显示什么。返回 null 表示走原 Window。
export function pickBookVoice(): BookVoice | null {
  if (Math.random() >= BOOK_VOICE_RATE) return null;
  return BOOK_VOICES[Math.floor(Math.random() * BOOK_VOICES.length)];
}
```

- 纯手写句池，**不接 LLM**
- 全部纯情绪（零名词），今天就能上线、不可能说错
- 句子都符合协议：第一人称、禁问句、禁判断词、禁比较

### `page.tsx` 改动（三处）

**1. 决定本页用 Window 还是 Book Voice（line 500 附近）**
```tsx
const currentWindow = useMemo(() => createWindowProvider().peekWindow(), []);
const currentBookVoice = useMemo(() => pickBookVoice(), []);  // 挂载时定一次
const activeVoiceText = currentBookVoice?.text ?? currentWindow.text;
const isBookVoice = currentBookVoice !== null;
```

**2. 传给 PageCard（line 692）**
```tsx
<PageCard ... promptText={activeVoiceText} ... />
```
PageCard 零改动——`promptText` 仍是 string。

**3. 视觉区分（line 424–430）**
Book Voice 用比 Window 更轻的样式，并加一个极淡的「书」标记，让用户下意识感到主体不同：
- Window：`text-stone-500/50`（现状）
- Book Voice：`text-stone-400/45 italic`，上方加一个 `text-[9px] text-stone-600/40 tracking-[0.3em]` 的「书」字

为此 PageCard 需要多收一个 prop `isBookVoice?: boolean`，在渲染处分支样式。改动仅限那一处 `<p>`。

### 埋点（两个事件，用于测稀有度）

用 `./_core/analytics` 的 `track`，保持 `v4_` snake_case：

- `track('v4_book_voice_shown', { voice_id })` —— 在 Book Voice 渲染时（PageCard mount / `isBookVoice` 为真）触发一次
- `track('v4_book_voice_followed_by_write', { voice_id })` —— 在 `handleAddParagraph` 里，若 `isBookVoice` 则额外触发

核心指标：两事件的比例。若 Book Voice 后的写入率 ≈ Window 后的写入率 → 无副作用，可保留/调高；若显著更低 → 它在抑制写作，调低或撤。
