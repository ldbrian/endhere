# Contributing to End Here

Thank you for your interest in contributing.

End Here is an open-source experiment exploring emotional reflection, personal state observation, and privacy-first digital wellbeing.

We welcome:

* bug reports
* documentation improvements
* design discussions
* architectural suggestions
* code contributions

Before opening a pull request, please:

1. Open an issue describing the proposed change.
2. Keep discussions respectful and constructive.
3. Follow existing project conventions whenever possible.

Our goal is not to maximize engagement, but to create healthier digital environments for reflection and observation.

Thank you for helping improve the project.
