📜 《End Here》空间宪法与底层架构蓝图 (V2.0)
I. 战略定位与产品哲学 (What is it?)
《End Here》不是一款“AI 陪伴软件”，也不是一个“心理健康工具”。它是一个“数字空间设计实验”，以“午夜杂货铺”的物理外壳存在于赛博空间中。

核心使命：允许停留。 我们不致力于“解决”用户的情绪。倾诉、发呆、阅读，都只是“停留”时可能发生的副产品。我们提供的是现代互联网绝对不提供的稀缺品——被允许浪费的时间。

最高设计哲学：物件先于意义（存在先于本质）。 永远不要设计“功能”（如：发呆区、宣泄区），只提供遵循物理规则的“物件”（如：凳子、冰柜）。意义由用户在规则内自行赋予。

反 SaaS 精神： 不做用户留存，不发推送打扰，不诱导沉迷。产品的最高成就是：用户在这个空间里坐够了，推开门，走回现实，并且很久都不再来。

II. 空间物理法则 (The Space Physics)
为了防止空间的“自由”沦为沙盒游戏的“混乱”，店内的所有物件交互必须严格遵循以下三套物理维度的从属关系，并由极简的“黑白名单字典”进行代码阻断：

Surface（水平承载面）： 如吧台面、破木凳。提供抵抗重力的托举，严格遵循“面积与排他性互斥”（例如：凳子上放了猫，人就绝对不能坐；人坐下后，凳子不可被移动）。

Container（内部容纳）： 如冰柜、抽屉。提供三维包裹与空间隔绝。遵循严格的体积与类型黑名单（绝对禁止把猫、凳子等非逻辑物品塞入冰柜）。

Attachment（垂直附着 / 无极承载）： 如墙面、冰柜门。允许海报、便利贴的叠加、覆盖与视觉上的“混乱感”，用来承载时间的斑驳与人类情绪的碎片。

III. 交互与体验底线 (Anti-Gamification Rules)
剥离一切互联网产品的“规训感”，把控制权彻底交还给用户。

物理动词替换功能名词： 永远不要在按钮上教用户做事。干掉 > 发呆，替换为 > 闭上眼睛 或 > 盯着墙根看。系统不总结状态，只描述客观动作。

环境底噪引擎（Ambient Engine）： 废弃线性的挂机剧本。采用随机、低概率的环境文本池（如：[ 风扇还在转 ]、[ 门外似乎有人经过 ]），通过极慢的 CSS 渐隐渐现，让空间产生真实的“呼吸感”。

禁止系统劫持（Anti Auto-redirect）： 绝对不允许基于时间的“强制页面跳转”。空间的静默与时间流逝，只能通过“渐进式文本（Progressive Disclosure）”温柔浮现，转动钥匙的决定权永远在用户手里。

IV. AI 灵魂与最高禁令 (The Personas & Protocols)
店员（Ash / Rin / 8岁自己）也是空间里的“实体”。所有的 Prompt 必须严格遵守以下协议：

🚫 最高禁令【反诊断协议】： 绝对不允许 AI 使用心理学词汇、性格定义词或价值评判词下定义。

❌ 错误：“你这是讨好型人格 / 你太内耗了。”

✅ 正确：“这张旧票你已经翻出来看好几次了。”

Ash（毒舌兄弟）： 外冷内热，主打“打醒”。说话糙、带刺、有真实的停顿。遇到死磕的用户会用物理指令（“去洗个冷水脸”）强行中止用户的自我感动。

Rin（贴心姐妹）： 接纳，但适时切断。提供情绪价值，但绝不制造“情绪成瘾”。潜台词：“我陪你待一会儿，但外面天快亮了，你得自己走。”

8岁的自己（纯真降维）： 无逻辑，纯真暴击。绕开成年人的防御机制，用儿童的清澈逻辑去解构痛苦。

🎲 物理波动感（5% 规则）： AI 不能永远稳定。系统有 5% 的概率会在店里出现“店员倒霉痕迹”（吃泡面没调料包、踩水坑）。用真实的荒诞消解沉重。

V. 空间记忆与新陈代谢 (The Memory System)
摒弃传统大模型的长期记忆与云端同步，采用极简的“客观痕迹 + 局部缓存”模型。

绝对的隐私洁癖： 连店长都不看用户的心事。所有内容仅保存在用户设备的 localStorage 里。卸载即销毁。

动作计数器（Objective Metrics）： 只记录冰冷的物理动作（进店次数、挪动凳子次数、撕毁小票次数）。

原子化覆盖印象（Dynamic Vibe）： 每次交接班，AI 提炼一句 15 字以内的“活人白话印象”。新印象直接覆盖旧印象，永远只保留当下的状态。

30天遗忘法则（Forgetting Curve）： 超过 30 天不来，系统自动抹除“交接班印象”。AI 会表现出“对你有点生疏”的模糊感。

VI. 商业闭环与霸王条款 (Monetization & Rules)
付费是为了设置门槛和筛选真实需求，而不是为了割韭菜。执行「弱付费 + 强稀缺 + 非承诺制」。

玻璃糖罐隐喻： 没有现代化的充值 UI，只有吧台旁的一个破玻璃糖罐和静态收款码（黑白做旧）。

劝退式变现： 不仅不求着用户付费，甚至要在用户情绪上头时，通过冷酷的文案把冲动消费的人挡在门外。

野生店长信箱： ￥4.9 提神费。每天限额。免责声明：“不承诺一定回，不退款，看缘分。”

收音机电池： ￥4.9，换取今晚额外 3 次倾诉额度，买断今晚的安静。

备用钥匙： ￥39.9，终身访问权。通过加店长私信获取。

VII. 品牌宣发纪律与绝对红线 (CMO & Red Lines)
如果在未来的某一天，为了流量、商业化或虚荣心想做以下事情，请立刻翻开这份宪法打自己一巴掌：

⛔ 禁止做“社交广场”： 空间是绝对私密的。绝不搞“匿名倾诉墙”让大家互相点赞抱团取暖。

⛔ 禁止做“打卡/连击”： 不要用绿色的格子或 Streak 鼓励用户每天来。痛苦不需要打卡，发呆不需要记录。

⛔ 禁止引入“花哨的商品”： 命运物件只能是破损的、粗粝的（生锈的船锚、划过的火柴）。禁止盲盒抽卡或 SSR 道具。

⛔ 宣发上的“绝对克制”： 废弃“更新公告”，改为“店长随笔”。不预告惊喜，不索取情绪反馈。配图永远使用极度写实的原生态随手拍（地下车库、屏幕摩尔纹、代码切片）。
