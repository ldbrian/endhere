# 修正 V2/app/page.tsx 三个需求

## 先说明一个技术现实（需求1）
当前代码其实**已经有真实光标**：`<textarea>` + `caret-stone-300` + `autofocus` + 多次 `.focus()` 尝试。你看到的"虚拟光标"是一个 `<motion.span>` 合成光标，只在 `!isFocused` 时显示。

根本原因：**移动端浏览器安全策略禁止程序化 `.focus()` 唤起键盘/原生光标**，必须有真实手指点击。这是 Web 平台硬限制，无法绕过。所以现状是"桌面端能用真实光标、移动端只能用虚拟光标"——这正对应你说的"点击才出现真实光标"（你在测移动端）。

按你"做不到就保持现状"的指示：**桌面端彻底去掉虚拟光标、只保留原生光标；移动端保留虚拟光标作为诚实兜底。** 通过 `window.matchMedia('(pointer: fine)')` 区分桌面/触屏。

- 桌面端 → 只有原生 `caret-stone-300` 闪烁，去掉合成层干扰。
- 保留 `autofocus` + setTimeout 多次 `.focus()` + `setSelectionRange(len,len)`，确保桌面端光标落在默认文案末尾。

## 需求2：两段式中间状态 + 停留当前页 + 轴上出现002
**状态改造：** 把 `isTracing: boolean` 替换为更细的 `submitPhase: 'idle' | 'saving' | 'generating' | 'revealed'`。

**`handleAddParagraph` 新流程：**
1. `phase='saving'`：立即 `appendParagraphToCurrentPage`（原文先落盘，narration 暂空，符合"这一页被保存了下来"的真实含义）→ 停留约 1000ms 让文案呼吸。
2. `phase='generating'`：调 organize API（首页仪式文案 `今天我第一次翻开这本书` 跳过 API，直接 saving→reveal；未改动的邀请文案仍走 API）。
3. reveal：用新 store action 把 response（narration/persona/artifact）写回刚才那段 → `finalizeCurrentPage({ title, stayOnCurrentPage: true })` 关闭当前页并追加空白002，**但不移动 currentPageIndex**（停留在001）→ `phase='idle'`。

**`PageCard` 渲染调整：**
- 已写满的页（paragraph 存在）分支里：当 `paragraph.trace` 为空且 `phase!=='idle'` 时，显示阶段徽标代替回应区：
  - saving：`这一页被保存了下来`
  - generating：脉动 `书正在接住这一页…`
- trace 到位后正常显示回应。
- `isWritable = isLatestPage && paragraphs.length===0 && phase==='idle'`。
- 修正"已写完"提示：原文 `向左翻到下一页` → `向右翻到下一页`（下一页在右侧，当前是 bug）。
- 提交进行中（phase!=='idle'）时禁用左右翻页箭头，避免中途切页导致状态错乱。

**文件：`app/v2/_core/storage.ts`**
- `finalizeCurrentPage` 新增 `{ stayOnCurrentPage?: boolean }` 选项：为 true 时不改 `currentPageIndex`，只关闭当前页+追加空白页。
- 新增 `setParagraphResponse(pageId, paragraphId, { narration, persona, artifact })`：定位段落、写入 response，并重建 `localFragments` 保持同步。（私密碎片不上云，无需 re-sync。）

## 需求3：右上角旧纸张入口 + 所有用户空数据起手
**文件：`app/v2/_core/storage.ts`（迁移）**
- 新增 `LegacyPage` 类型（page_number/title/paragraphs[{text,trace,persona,timestamp}]/closed_at）与 `legacyArchive: LegacyPage[]` 状态（默认 `[]`）。
- persist `version: 3 → 4`，重写 `migrate`：把旧 book 中**有内容的页**转成 `legacyArchive`，然后 `book = createInitialBook(ownerId)`（全新空001），`currentPageIndex=0`，`localFragments=[]`。**所有用户（新老）都以空书起手，旧数据进陈列。**
- `partialize` 加入 `legacyArchive`。

**文件：`app/v2/page.tsx`（入口 + 陈列组件）**
- Header 右侧（安装图标旁）新增一个"旧纸张"小图标按钮，**始终显示**。
- 新增 `LegacyArchive` 覆盖层组件：旧纸张视觉（泛黄、纸质纹理、毛边），纵向陈列所有 `legacyArchive` 页（页码 + 标题 + 原文 + 回应），**只读**。archive 为空时显示温和空状态（如"还没有旧页可翻"）。关闭按钮收起。
